# CHAOSBOX

CHAOSBOX is a modular 3D physics sandbox prototype made with Godot Engine 4. The repository starts from a clean project and is being developed in stages.

## Run

1. Open `project.godot` with Godot 4.x.
2. Press **Play** (F6/F5, or the editor's main-scene Play button).

The first foundation build contains a generated test facility, first-/third-person camera toggle, character movement, and a minimal in-game HUD. It uses built-in Godot meshes and materials; no external assets are required.

## Controls

- WASD: move
- Shift: sprint
- Space: jump
- Ctrl: crouch
- Mouse: look
- V: toggle first-/third-person camera
- Tab: show prototype tool information
- Esc: pause / release mouse
